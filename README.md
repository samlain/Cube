# Cube 
Cube Card Game is a Java-based desktop application that challenges players to test their intuition by predicting whether the next card drawn from a shuffled deck will be higher, lower, or the same as the currently revealed card in a selected pile. At the start of the game, nine cards are dealt and displayed in a 3x3 grid. The player selects a card pile and chooses one of three options: Higher, Lower, or Same. If the guess is correct, the card is replaced with a new one, and the player continues with that pile. However, if the guess is incorrect, the pile turns red and becomes inactive. The game continues until the deck is depleted or all piles have turned red. If all piles are disabled before the deck runs out, the game ends in a loss.

The game is built following the Model-View-Controller (MVC) design pattern. The CubeModel class manages the deck of cards, shuffling, and tracking game progress. The CubeView class constructs the graphical user interface using Java Swing, displaying the cards, buttons, and counters. The CubeController connects the model and view, handling all game logic including user input, result evaluation, and game resets. Features include animated card transitions with scaled image icons, sound effects that indicate correct or incorrect guesses, and a card counter that updates as the game progresses. A restart button allows players to reset the game at any time, reshuffling the deck and clearing all piles.

To run the game, ensure that Java 8 or later is installed on your system. Card images must be stored in a deck/ folder, and sound effects (correct.wav and wrong.wav) should be placed in a sound/ directory within the project folder. After compiling the Java files using javac *.java, the game can be launched by executing java CubeMain. The interface opens in full-screen mode and provides an intuitive layout with card selection, guess buttons, and game controls.

Future improvements for the game include implementing keyboard controls (such as ‘H’ for higher, ‘L’ for lower, ‘S’ for same), adding arrow key and Enter navigation for card selection, and creating a full-featured menu system with a leaderboard and user login/sign-up screens. The interface also includes a placeholder for rule explanations and future functionality to display high scores.
